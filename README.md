# neuro-networks
  
    Run numpy on the gpu for much faster performance. Using CuPy
CuPy can use the nividia driver: CUDA. Install the driver and other dependecies. Other gpu drivers also work. Example amd /n
  CuPy: https://cupy.dev/
Use this command to get the nividia CUDA version. CUDA is a driver api for developers to use the gpu 
  nvcc --version
